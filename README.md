# 时煜创科技 · 财务工作台

**在线体验**：https://xiao-shi-feng.github.io/tax-reminder/

一个轻量、开箱即用的财务工作台，主打**税务申报提醒**，集成常用网址、付款计划、待办备忘、账户信息五大模块。纯前端（HTML + CSS + JS），无后端依赖，数据存在浏览器 `localStorage`，支持 PWA 离线使用、手机端安装到桌面。

---

## ✨ 核心功能

| 模块 | 说明 |
|------|------|
| **📋 税务申报** | 税种/周期/截止日/状态/核对结果/金额/备注全维度记录，月份筛选，汇总统计，**申报提醒一目了然** |
| **🔗 常用网址** | 税务局、电子税务局、银行、政务平台一键直达，分类+搜索+图标，自定义增删改 |
| **💳 付款计划** | 月度付款计划表，对象/内容/日期/金额/状态/进度条，自动汇总本月应付/已付/待付 |
| **✅ 待办备忘** | 按日期分组，进度条可视化，勾选完成自动划线，今日/本月/已完成计数 |
| **🏦 账户信息** | 多主体工商/法人/银行信息，分区复制粘贴，编辑即时保存 |

## 🚀 快速开始

### 方式一：直接访问在线版（推荐）
打开 https://xiao-shi-feng.github.io/tax-reminder/ 即用，数据自动存在你浏览器里。

### 方式二：本地离线用
```bash
git clone https://github.com/xiao-shi-feng/tax-reminder.git
cd tax-reminder
# 直接双击 index.html 用浏览器打开，或用任意静态服务器
# 例：python3 -m http.server 8080  然后访问 http://localhost:8080
```

### 方式三：手机安装为 App（PWA）
1. 手机浏览器打开在线地址
2. 点击菜单 → **「添加到主屏幕」/「安装应用」**
3. 桌面生成图标，离线也能打开、查看、编辑

## 📖 详细使用指南

### 1️⃣ 税务申报 —— 核心功能
- **新增**：点击右上角 `+ 新增申报项`，填税种（如「增值税」）、申报周期（年月）、截止日、状态、核对结果、金额、备注
- **筛选**：顶部月份选择器切换月份，汇总栏实时显示「待申报 / 已完成核对 / 异常提醒 / 本月应交税额合计」
- **行内编辑**：点「编辑」修改任意字段，状态四选项：`待申报` `即将到期` `已完成` `异常`
- **状态色标**：`待申报`(蓝) `即将到期`(橙) `已完成`(绿) `异常`(红)
- **数据持久**：关闭浏览器、换设备（同浏览器登录账号同步）不丢失

### 2️⃣ 常用网址
- **新增**：`+ 添加网址`，支持 Emoji 图标、分类、描述
- **搜索/筛选**：顶部输入框搜名称/网址，下拉框按类别过滤
- **点卡片** = 新标签页打开网站，**编辑/删除** 悬停显示
- **预置建议类别**：税务平台、银行、政务、内部系统、工具类

### 3️⃣ 付款计划
- 月份切换同税务申报
- 状态三选项：`待付`(灰) `审批中`(蓝/进度 50%) `已付`(绿/进度 100%)
- 汇总栏自动算：本月应付总额 / 已付 / 待付

### 4️⃣ 待办备忘
- 按日期倒序分组，**今天/昨天** 自动显示中文标签
- 进度条 0-100%，勾选复选框 = 完成（划线 + 进度 100%）
- 统计：今日待办 / 本月待办 / 已完成数量

### 5️⃣ 账户信息（多主体）
- 公司工商、法人、银行三区块，**每区块右上角「复制」= 一键复制整段文本**（粘贴到 Excel/邮件/钉钉极快）
- 必填：公司名称、统一社会信用代码、开户银行、银行账号
- 支持多家公司切换，编辑即时保存

## 🛠️ 技术栈 & 架构

| 层级 | 技术 |
|------|------|
| 结构 | 单页 HTML（语义化标签 + 语义化 class） |
| 样式 | 原生 CSS（CSS 变量、Grid/Flex、媒体查询、安全区适配、暗色模式预留） |
| 逻辑 | 原生 ES6+ JS（模块化函数、localStorage 持久化、事件委托、XSS 转义） |
| PWA | `manifest.webmanifest` + `sw.js`（Cache First 策略、离线兜底） |
| 部署 | GitHub Pages + GitHub Actions（push main 自动构建部署） |

**零依赖、零构建、零后端** —— 克隆即用，拷贝 `index.html` 到任意静态服务器即可跑。

## 🔧 自定义 & 扩展

### 修改主题色
编辑 `index.html` 顶部 `:root` CSS 变量：
```css
:root {
  --primary: #2563eb;   /* 主品牌色 */
  --bg: #f5f7fa;        /* 页面底色 */
  --card-bg: #ffffff;   /* 卡片底色 */
  /* ...更多变量 */
}
```

### 新增税种/状态/分类
在 JS 里对应数组/对象里增项即可（如 `statusTag()`、`categoryStyle()`、`modalConfigs.tax.fields`）。

### 接入后端同步
`saveStore()` / `loadStore()` 两个函数集中读写 `localStorage`，替换为 `fetch('/api/...')` 即可接后端。
